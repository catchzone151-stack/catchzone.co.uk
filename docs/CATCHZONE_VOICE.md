# CatchZone Voice — Website Implementation Notes

CatchZone Voice is a product of CatchZone Ltd (not a separate company). This
document covers the website presence added in the Voice pass. Operational
details for the live demo are in `docs/VOICE_DEMO_OPERATIONS.md`.

## Routes

| Route | Purpose / search intent |
| --- | --- |
| `/voice` | Product page. Real-time AI voice translation, live speech-to-speech translation, English–Spanish live voice translation. Conversation Studio is the centrepiece; product content is server-rendered beneath it. `SoftwareApplication` + `BreadcrumbList` JSON-LD. |
| `/voice/languages` | Supported-language catalogue (60), search + group/RTL filters, deep links into the Studio (`/voice?from=en&to=fr#studio`). `BreadcrumbList`. |
| `/voice/business` | Contact centres, travel support, bookings, hospitality. Integration routes (subject to technical assessment), FAQ. `FAQPage` + `BreadcrumbList`. |
| `/api/voice/status` | Availability for the Studio (never contacts Soniox). |
| `/api/voice/session`, `/api/voice/session/end` | Public demo trial start/end (see runbook). |
| `/api/voice/enquiry` | Voice enquiry form → Resend when `RESEND_API_KEY`/`RESEND_TO_EMAIL` are set; otherwise reports `unconfigured` and the UI offers a mailto fallback. |

All three pages share `VoiceSubnav` (product nav + breadcrumbs) and
`VoiceContact` (contact section + short form). Sitemap updated; `/api/` was
already disallowed in robots.

## Single source of truth for languages

`src/data/voice/soniox-languages.json` is generated by
`scripts/voice/sync-soniox-languages.mjs` from Soniox's official STT,
translation and TTS language tables (identical 60-language sets; translation
between any pair). Native names and text direction come from Unicode CLDR via
Node's `Intl`, with three documented overrides (`tl`, `id`, `ms`). TTS script
restrictions (Serbian/Bosnian Latin, Kazakh Cyrillic, Chinese Simplified) are
carried as `speechOutputNote`. `src/data/voice/languages.ts` exposes it and
fails the build if display groups drift from the catalogue.

## Technology facts used on the site (verified 14 Nov 2026)

- Soniox real-time STT model `stt-rt-v6`; TTS model `tts-rt-v2`.
- Two-way translation config `{ type: "two_way", language_a, language_b }`;
  tokens carry `translation_status` (`original` / `translation` / `none`).
- Soniox security page: no retention of real-time audio/transcripts, no model
  training on customer data, usage metadata kept for billing/debugging. The
  site attributes these statements to Soniox rather than presenting them as
  CatchZone guarantees.
- No latency/accuracy figures are published on the site. STT, translation and
  TTS are described as separate stages; end-to-end performance is described
  as variable.

## Claims deliberately NOT made

No testimonials, client logos, customer counts, accuracy percentages,
latency figures, SLAs, pricing, published API, UJET/loveholidays, universal
telephony plug-in, accent conversion, noise cancellation, call summaries,
agent assist or quick phrases.

## SEO notes

Keyword targeting was written from the intents in the brief; no search-volume
or ranking data was available or measured. Titles ≤ 60 characters and
descriptions ≤ 160 characters. Each page targets a distinct intent to avoid
cannibalisation (product / languages / business). Existing routes, canonicals
and redirects are unchanged.
